# WhoDat Oyun Sesleri (Sound Effects)

Bu klasöre ElevenLabs Sound Effects ile ürettiğiniz MP3 ses dosyalarını yükleyebilirsiniz.

### Format
**MP3** (128 kbps veya 192 kbps, stereo/mono, düşük dosya boyutu).

---

### Ana Oyun Sesleri
1. `correct-guess.mp3` - **Tur İçi Doğru Tahmin** (+10 Puan) (Neşeli retro zil, hafif alkış/konfeti)
2. `game-victory.mp3` - **Oyun Sonu Zafer / Şampiyonluk** (Büyük zafer fanfarı / parti kutlaması)
3. `wrong-guess.mp3` - **Yanlış Tahmin / Can Kaybı** (Ahşap tokmak / komik buzzer / hafif hayal kırıklığı)
4. `card-flip.mp3` - **Kart / Sayfa Çevirme & Pas Sesi** (Gerçekçi kağıt hışırtısı / defter sayfası çevirme, pas durumunda da kullanılır)
5. `vote-ping.mp3` - **Canlı Oylama Başlama Zili** (Tatlı marimba / bildirim pinglemesi)
6. `countdown-tick.mp3` - **Geri Sayım Tik-Tak** (Son 5 saniye ahşap saat tik-takları)
7. `pencil-scribble.mp3` - **Kalem Çizimi** (Soru sorarken veya not alırken kağıtta kurşun kalem sesi)

---

### Arayüz (UI) Ses Efektleri
9. `button-tap.mp3` - **Buton Tıklama** (Tok, hafif ahşap/kağıt kutu tıklaması)
10. `modal-open.mp3` - **Panel / Çekmece Açılma** (Alttan açılan skor/ipucu sayfası için yumuşak kayma sesi)
11. `dice-roll.mp3` - **Rastgele / Zar Sesi** ("Botlara Karşı Oyna" veya rastgele soru çekerken zar sesi)
12. `check-tick.mp3` - **Kalemle Tik Atma** (Hazır olunduğunda veya onay verildiğinde kurşun kalem tik sesi)
13. `round-start.mp3` - **Tur Başlama Düdüğü / Tınısı** (Yeni tur başlarken yükselen ksilofon tınısı)
